Git & GitHub — Summary
1. What is Git?

Git is a Version Control System (VCS) used to track changes made to files in a project.

It allows us to:

Track the history of our code.
Save different versions of a project.
Go back to an older version if something goes wrong.
Work on different features using branches.
Collaborate with other developers.

Git works locally on your computer.

2. What is GitHub?

GitHub is a cloud-based platform that hosts Git repositories online.

It helps us:

Store our projects online.
Share code with others.
Collaborate with developers.
Backup our repositories.
Manage projects using issues, pull requests, etc.

GitHub works online, while Git is the version-control software.

3. Git vs GitHub
Git	GitHub
Version Control System	Online code-hosting platform
Works mainly locally	Works through the internet
Tracks changes in code	Hosts Git repositories
Created by Linus Torvalds	Owned by Microsoft
Can work without internet	Usually requires internet for remote operations

Simple example:
Git = the tool that manages your project's versions.
GitHub = the online place where you can store and share that Git project.

4. Important Git Terms

Repository (Repo):
A folder/project tracked by Git.

Working Directory:
The files you are currently working on.

Staging Area:
A temporary area where you select changes that should be included in the next commit.

Commit:
A saved snapshot of your project at a particular point in time.

Branch:
A separate line of development used to work on features without disturbing the main code.

Remote:
The online version of your repository, usually hosted on GitHub.
